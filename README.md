# super-competency-analysis
2023 경진대회 - SUPER 역량 분석

## 🏙️ SUPER 핵심역량 비교과 분석
전주대학교 빅데이터 분석 경진대회 | 장려상 (3위) | 2023

전주대학교 SUPER 핵심역량 비교과 과목 개설 현황 데이터를 분석해
특정 역량에 편중된 구조를 발견하고 개선 방안을 제안한 프로젝트입니다.

## 🔍 핵심 발견

- P(자기개발) 역량 과목 4,076개 — 전체 비교과의 **43%** 차지
- E(창의융합) 역량 — 참여형 수업의 **52%** 로 편중
- E역량 과목명 텍스트 마이닝 결과, ICT와 무관한 체험·만들기 위주 키워드 다수 확인
- 2018~2023년 단대별 SUPER 역량 평균 시계열 분석으로 변화 추세 확인

## 📊 분석 흐름

1. **현황 분석** — 역량별 비교과 과목 수 및 비율 산출
2. **시계열 분석** — 2018~2023년 단대별 역량 평균 연도별 추이
3. **텍스트 마이닝** — 과목명 형태소 분석 후 워드클라우드 시각화
4. **문제 특정** — E역량 과목의 정의-배정 불일치를 데이터로 증명
5. **개선 방안 제안** — E역량 다양화 프로그램 2개 제안

## 💡 제안 방안

- 창의문제해결력 경진대회 개설
- 브레인스토밍 세션 도입 (ICT 리터러시 연계)
